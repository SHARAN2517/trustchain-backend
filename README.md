**Trustchain-Med AI** is an end-to-end multimodal, privacy-preserving, and explainable diagnostic clinical intelligence system. It seamlessly fuses high-fidelity medical imaging (using Convolutional Neural Networks and Vision Transformers) with unstructured clinical text narratives (using Bio_ClinicalBERT) via a custom Cross-Attention Fusion layer.

## 🚀 Key Features Added to the Core Backend

### 1. Multimodal Diagnostic Fusion Engine (`model.py`)
*   **Cross-Attention Fusion Layer**: Fuses spatial image grid representations extracted by a **Vision Transformer (ViT-B/16)** with semantic embeddings generated by a **Bio_ClinicalBERT** encoder.
*   **Modality Auto-Routing**: A highly calibrated Conv2D modality detector automatically parses uploads and routes them to four specialized clinical classifiers:
    1.  **Radiology** (X-ray, CT, MRI using ChestMNIST mappings)
    2.  **Cardiology** (12-lead ECG waveforms and Echocardiograms)
    3.  **Pediatrics** (Childhood Growth Charts and EHR logs)
    4.  **Oncology** (Histopathology biopsy tissue cell slides)

### 2. Live High-Fidelity FastAPI API Service (`main.py` & `app.py`)
*   **`/predict` (Inference Endpoint)**: Accepts uploaded images (scans/waveforms/slides) and text notes, performs full forward passes, and returns primary diagnoses, confidence metrics, quality indicators, OOD (Out-of-Distribution) checks, and cryptographic proofs.
*   **`/gradcam` (Visual Attentions)**: Implements **Grad-CAM Plus Plus** backpropagation, targeting Conv2D layers to highlight spatial activation hotspots. Returns overlaid heatmaps dynamically as Base64 strings.
*   **`/explain` (Text Drivers)**: Tokenizes clinical notes and extracts importance attributions using gradient magnitude computations mapped to Bio_ClinicalBERT vocabularies. Returns sorted top-5 contributing words.
*   **`/blockchain/proofs` & `/reputation/{hospital_id}`**: Interacts with a local SQLite ledger registering federated weights, hashes, signatures, and transaction IDs to construct a searchable audit trail of federated updates.

### 3. Real Clinical DICOM (`.dcm`) Scanner Support
*   **Ingestion & Contrast Normalization**: Leverages `pydicom` to parse raw scanner `.dcm` files. Auto-extracts `WindowCenter` and `WindowWidth` tags (with robust list-type extraction), applies clip scaling, normalizes high-dynamic-range pixel arrays, and renders standard RGB images for inference.

### 4. Privacy-Preserving Security (`privacy.py`)
*   **Differential Privacy (DP-SGD)**: Wraps PyTorch training loops using Opacus. Enforces gradient clipping and injects calibrated Gaussian noise to defend against **Membership Inference Attacks (MIA)** while calculating exact Rényi Differential Privacy (RDP) budgets ($\epsilon$, $\delta$).

### 5. Decentralized Federated Learning Layer (`federated.py`)
*   **Flower (flwr) Integration**: Secure Client-Server infrastructure enabling remote hospitals to participate in decentralized rounds, averaging weights safely without exchanging raw clinical records.

### 6. Rhythm & Pathology Coexistence Engine
*   **Multi-Label Classification**: Allows complex cardiology and pathology classifications to co-exist with independent logits (e.g. diagnosing *Atrial Fibrillation / STEMI* alongside *Normal Sinus Rhythm* with high confidence instead of using mutual exclusion).

## 🛠️ Local Installation & Setup

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/SHARAN2517/trustchain-backend.git
    cd trustchain-backend
    ```

2.  **Set Up a Virtual Environment** (Recommended):
    ```bash
    python -m venv venv
    # Windows
    .\venv\Scripts\activate
    # macOS/Linux
    source venv/bin/activate
    ```

3.  **Install Required Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Run the Local FastAPI Server**:
    ```bash
    python app.py
    # OR using uvicorn directly
    uvicorn main:app --host 127.0.0.1 --port 8000 --reload
    ```
    *The API will be live at `http://127.0.0.1:8000`. You can inspect endpoints via the interactive Swagger docs at `http://127.0.0.1:8000/docs`.*

## 📡 API Endpoint Reference

### 1. Run Diagnostic Inference
*   **Endpoint**: `POST /predict`
*   **Content-Type**: `multipart/form-data`
*   **Parameters**:
    *   `file` *(Optional File)*: Image file (`.png`, `.jpg`, `.dcm` DICOM format)
    *   `note` *(Form String)*: Patient clinical narrative
    *   `specialty` *(Form String)*: "Auto-detect" or specific department
    *   `patient_id` *(Form String)*: Anonymous identifiers
    *   `hospital_id` *(Form String)*: Node registrar identifier

### 2. Generate Grad-CAM Heatmap
*   **Endpoint**: `POST /gradcam`
*   **Content-Type**: `multipart/form-data`
*   **Parameters**:
    *   `file` *(Required File)*: Medical image file
    *   `specialty` *(Form String)*: Specialty classifier target (Radiology)
*   **Returns**: Base64-encoded heatmap overlay.

### 3. Extract Top-5 Clinical Drivers
*   **Endpoint**: `POST /explain`
*   **Content-Type**: `application/x-www-form-urlencoded`
*   **Parameters**:
    *   `note` *(Required String)*: Clinical note report text
    *   `specialty` *(Optional String)*: Target department
*   **Returns**: Shapley token rankings.

### 4. Fetch Blockchain Audit Trail
*   **Endpoint**: `GET /blockchain/proofs`
*   **Parameters**:
    *   `hospital_id` *(Optional String)*: Filter by institution
*   **Returns**: SQLite block list of signed weight updates, hashes, and hashes.
